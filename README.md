# The Trace Protocol — Android App

A 100% offline, local-first Android application designed to execute **The Trace Protocol**—a 4-stage systematic deconstruction of inherited beliefs, institutional rules, and personal friction.

## Security & Architecture
- **Zero-Network Guarantee:** Excludes `android.permission.INTERNET`.
- **Stack:** Kotlin, Jetpack Compose, Material 3, Room DB.
- **Local Persistence:** On-device SQLite (`trace_local_db`).

## The Four Stages

| Stage | Name | Question it forces |
| ----- | ---- | ------------------ |
| 1 | The Assertion | What is the core belief or rule that makes your life heavy? |
| 2 | The Genealogy | Who taught you this — and who taught them? |
| 3 | The Beneficiary | Who profits from your continued belief in this rule? |
| 4 | The Cost Audit | What monthly drain (hours and dollars) does maintaining it require? |

Completed traces are committed to the local vault, where they can be reviewed or purged.

## Zero-Network Guarantee

`app/src/main/AndroidManifest.xml` declares **no permissions at all** — in particular
no `android.permission.INTERNET`. On Android, a process without that permission is
denied socket creation by the kernel, so the app cannot transmit a trace off the device
regardless of what any library attempts. `android:allowBackup="false"` additionally
keeps records out of cloud backup and adb backup.

## Getting Started

Open the project root in **Android Studio** (Koala 2024.1.1 or newer, which ships the
AGP 8.5 support), let Gradle sync, then run the `app` configuration on a device or
emulator.

To build from the command line you need an Android SDK with platform 34 installed, and
either `ANDROID_HOME` exported or a `local.properties` file at the project root:

```properties
sdk.dir=/path/to/Android/Sdk
```

Then:

```bash
./gradlew assembleDebug     # debug APK -> app/build/outputs/apk/debug/
./gradlew assembleRelease   # minified release APK (R8 enabled)
```

`local.properties` is gitignored — the SDK path is machine-local and never committed.

## Data Model

A committed trace is one `trace_records` row:

| Column | Type | Source |
| ------ | ---- | ------ |
| `id` | Long (autogenerated) | primary key |
| `timestamp` | Long | commit time, used for vault ordering |
| `assertion` | String | Stage 1 |
| `directOrigin` | String | Stage 2 — who taught you |
| `ancestralOrigin` | String | Stage 2 — who taught them |
| `beneficiary` | String | Stage 3 |
| `category` | String | classification of the cost |
| `costHours` | Float | Stage 4 — monthly hours |
| `costDollars` | Float | Stage 4 — monthly dollars |

The database file lives in the app's private storage
(`/data/data/com.trace.app/databases/trace_local_db`), unreadable by other apps under
Android's per-app UID sandbox. Uninstalling the app destroys the vault; there is no
export path and no remote copy, by design.
